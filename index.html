Moneypenny Artifact Pilot

Moneypenny Artifact Pilot saves the run log, audit report, and dashboard generated by the operator’s Moneypenny routines. Claude coordinates the routines. A service on the operator’s Windows computer verifies the files in Google Drive.

Why the app requests Drive access

Read-only metadata access lets the service check folder membership, file identity, size, and creation time. Google grants this metadata access across the account. The service uses it to list the configured artifact folder. Per-file access lets the service create the three kinds of generated files and download its creations to compare their original bytes. A local operation journal helps prevent duplicate uploads after a network failure.

This is a personal integration for the operator’s account. Questions about the app can be sent to the support address on its Google consent screen.
