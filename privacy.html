Privacy policy for Moneypenny Artifact Pilot

The operator uses this personal integration to save generated reports to a designated Google Drive folder and verify delivery. This policy covers the artifact service and its Google Drive authorization.

Data accessed and how it is used

The service reads the authorized account’s email address to check that the operator selected the intended account. Google grants read-only access to Drive metadata across that account. The service requests metadata for the configured folder and its children, including filenames, object IDs, parent IDs, creation times and available file sizes. It uses per-file access to create generated logs, audit reports and dashboards, and to download those files to verify their bytes. These reports can contain information derived from the operator’s inbox.

Processing and storage

The operator’s Claude cloud routine sends a generated file and its verification information over HTTPS to the Home service. Anthropic’s environment proxy supplies the service credential. Tailscale provides the HTTPS route. Google hosts the files in the operator’s Drive. The service processes the submitted files using temporary local storage and returns a receipt to the routine. Its local journal retains operation IDs, file metadata, content hashes, verification status and receipts so interrupted operations can be investigated. Windows user protection secures the stored Google refresh credential.

Drive access serves publication, verification and recovery. The operator does not sell Google user data, use it for advertising or use it to train a general-purpose AI model. Use and transfer of information received from Google APIs follow the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Generated artifacts remain in the operator’s Drive until the operator removes them. The local journal is retained for duplicate prevention and recovery. Revoking access in the Google Account connections page stops future authorized access once the revocation takes effect. Existing files and journal records can be addressed separately by contacting the operator at the support address displayed on the consent screen.
